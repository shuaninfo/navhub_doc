# Widgets

NavHub provides a variety of widgets to customize your dashboard.

## Available Widgets

| Widget | Description |
|--------|-------------|
| [Clock](./clock.md) | Display time, date, and timezone |
| [Weather](./weather.md) | Current weather and forecast |
| [Bookmarks](./bookmarks.md) | Quick access links |
| [RSS Feed](./rss.md) | News and updates from RSS sources |
| [Notes](./notes.md) | Quick notes and reminders |
| [Search](./search.md) | Custom search providers |
| [iframe](./iframe.md) | Embed external content |

## Widget Basics

### Adding a Widget

1. Click the "+" button on any page
2. Select the widget type
3. Configure widget settings
4. Click "Add"

### Moving Widgets

- **Drag and Drop** - Click and drag any widget to reposition
- **Resize** - Drag the corners to resize (where supported)

### Widget Settings

Click the gear icon on any widget to access:

- **Title** - Custom widget title
- **Size** - Widget dimensions
- **Refresh** - Auto-refresh interval
- **Visibility** - Show/hide conditions

### Removing a Widget

1. Click the widget menu (three dots)
2. Select "Remove"
3. Confirm deletion

## Creating Custom Widgets

Developers can create custom widgets using the Widget API. See the [API Reference](../api/README.md) for details.
