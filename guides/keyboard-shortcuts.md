# Keyboard Shortcuts

Speed up your NavHub workflow with these keyboard shortcuts.

## Global Shortcuts

Available from anywhere in NavHub:

| Shortcut | Action |
|----------|--------|
| `/` | Open search |
| `n` | Add new bookmark |
| `Esc` | Close modal/search |
| `?` | Show shortcut help |

## Navigation

| Shortcut | Action |
|----------|--------|
| `g` then `h` | Go to Home |
| `g` then `s` | Go to Settings |
| `g` then `b` | Go to Bookmarks |
| `1` - `9` | Switch to page 1-9 |
| `←` `→` | Previous/Next page |

## Search

| Shortcut | Action |
|----------|--------|
| `/` | Focus search |
| `Enter` | Open first result |
| `↑` `↓` | Navigate results |
| `Ctrl+Enter` | Open in new tab |
| `Esc` | Close search |
| `Tab` | Cycle filters |

## Bookmark Actions

| Shortcut | Action |
|----------|--------|
| `n` | New bookmark |
| `e` | Edit selected bookmark |
| `d` | Delete selected bookmark |
| `s` | Star/unstar bookmark |
| `t` | Add tag to selected |
| `m` | Move to folder |
| `c` | Copy URL |
| `o` | Open bookmark |
| `Shift+o` | Open in new tab |

## Selection

| Shortcut | Action |
|----------|--------|
| `j` | Select next bookmark |
| `k` | Select previous bookmark |
| `x` | Toggle selection |
| `Ctrl+a` | Select all |
| `Esc` | Clear selection |

## Bulk Actions

When multiple bookmarks selected:

| Shortcut | Action |
|----------|--------|
| `Shift+t` | Tag all selected |
| `Shift+m` | Move all selected |
| `Shift+d` | Delete all selected |
| `Shift+e` | Export selected |

## Widgets

| Shortcut | Action |
|----------|--------|
| `w` | Add widget |
| `Ctrl+↑` `↓` `←` `→` | Move selected widget |
| `Ctrl+Shift+↑` `↓` | Resize widget |
| `Backspace` | Remove selected widget |

## Pages

| Shortcut | Action |
|----------|--------|
| `p` | New page |
| `Ctrl+p` | Page settings |
| `1` - `9` | Quick switch pages |
| `[` | Previous page |
| `]` | Next page |

## Browser Extension

When extension popup is open:

| Shortcut | Action |
|----------|--------|
| `Enter` | Save bookmark |
| `Tab` | Next field |
| `Ctrl+Enter` | Save and close |
| `Esc` | Cancel |

### Global Extension Shortcuts

Set in browser extension settings:

| Default | Action |
|---------|--------|
| `Ctrl+Shift+S` | Save current page |
| `Ctrl+Shift+B` | Open NavHub |

## Customizing Shortcuts

Change shortcuts to fit your workflow:

1. Go to Settings → Keyboard
2. Find the action you want to change
3. Click the current shortcut
4. Press your new key combination
5. Click Save

### Reset to Default

1. Go to Settings → Keyboard
2. Click **Reset All** at the bottom
3. Confirm reset

## Tips

1. **Learn incrementally** — Start with `/`, `n`, and `Enter`
2. **Use vim-style navigation** — `j`/`k` for selection
3. **Two-key combos** — `g` then `h` for "go home"
4. **Muscle memory** — Practice daily for a week
5. **Print this page** — Keep as reference
