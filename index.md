# NavHub Help Center

Welcome to the NavHub Help Center! Here you'll find everything you need to get started and make the most of NavHub's features.

## What is NavHub?

NavHub is a smart personal navigation platform that helps you:

- **Organize bookmarks** — Say goodbye to messy browser bookmarks with tags and categories
- **Build your dashboard** — Customize with widgets: weather, to-dos, news, and more
- **AI assistant** — Auto-categorize bookmarks, smart summaries, AI-powered search
- **Sync everywhere** — Browser extension + web app, access from anywhere
