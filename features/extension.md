# Browser Extension

The NavHub browser extension lets you save bookmarks instantly from any webpage without leaving the site.

## Installation

### Chrome / Edge

1. Visit the [Chrome Web Store](https://chrome.google.com/webstore)
2. Search for "NavHub"
3. Click **Add to Chrome**
4. Confirm the installation

### Firefox

1. Visit [Firefox Add-ons](https://addons.mozilla.org)
2. Search for "NavHub"
3. Click **Add to Firefox**
4. Confirm the installation

### Safari (Coming Soon)

Safari extension is in development.

## Signing In

After installation:

1. Click the NavHub extension icon
2. Click **Sign In**
3. Enter your NavHub credentials
4. You're ready to save bookmarks!

## Saving Bookmarks

### Quick Save

The fastest way to save:

1. Navigate to any webpage
2. Click the NavHub extension icon
3. Click **Save**

The bookmark is saved with auto-detected title, description, and thumbnail.

### Save with Details

For more control:

1. Click the NavHub extension icon
2. Edit title if needed
3. Add or modify description
4. Select folder and add tags
5. Click **Save**

### Keyboard Shortcut

Save even faster with keyboard:

- **Windows/Linux:** `Ctrl + Shift + S`
- **Mac:** `Cmd + Shift + S`

Customize the shortcut in extension settings.

## Extension Features

### Auto-Fill

When you click the extension, it automatically:

- Fetches page title
- Extracts meta description
- Captures thumbnail image
- Detects page language

### Tag Suggestions

The extension suggests tags based on:

- Your existing tags
- Page content
- AI analysis (if enabled)

### Folder Quick-Select

Quickly choose a folder:

- Recent folders shown first
- Search for any folder
- Create new folder inline

### Screenshot Capture

Capture a screenshot of the page:

1. Click **Capture** in the save dialog
2. Choose: Full page or visible area
3. Screenshot saved with bookmark

## Extension Settings

Click the gear icon in the extension popup:

| Setting | Description |
|---------|-------------|
| Default folder | Where to save by default |
| Auto-save | Save immediately without popup |
| Screenshot | Auto-capture screenshots |
| Notifications | Show save confirmations |
| Keyboard shortcut | Customize the hotkey |

## New Tab Override

Replace your new tab page with NavHub:

1. Go to extension settings
2. Enable **New Tab Override**
3. Open a new tab to see your NavHub dashboard

**Note:** This requires additional permission that you'll be prompted to grant.

## Right-Click Menu

Save bookmarks from the context menu:

1. Right-click anywhere on a page
2. Select **Save to NavHub**
3. Bookmark is saved instantly

Right-click on a link to save that specific URL without visiting it.

## Troubleshooting

### Extension Not Working

1. Check you're signed in
2. Refresh the page
3. Try disabling/re-enabling the extension
4. Clear browser cache

### Can't Sign In

1. Verify your credentials at navhub.info
2. Check if you have 2FA enabled
3. Try signing out and back in
4. Contact support if issues persist

### Missing Features

Some features require Pro plan:
- AI tag suggestions
- Screenshot capture
- Bulk operations

## Privacy

The extension:

- Only activates when you click it
- Doesn't track browsing history
- Only sends data when you save a bookmark
- All transmission is encrypted
