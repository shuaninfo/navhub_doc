## Core Features

### 📚 Bookmark Management

Organize your links with powerful tools:

- **Tags** — Add multiple tags to any bookmark for flexible categorization
- **Folders** — Traditional folder structure when you need hierarchy
- **Notes** — Add personal notes and descriptions to bookmarks
- **Thumbnails** — Visual previews for quick recognition

[Learn more about Bookmark Management →](./bookmarks.md)

### 🧩 Widget System

Build your perfect dashboard:

- **Clock** — Time, date, multiple timezones
- **Weather** — Current conditions and forecast
- **Bookmarks widget** — Quick access links
- **To-do list** — Track your tasks
- **RSS feeds** — News from your favorite sources
- **Search bar** — Custom search providers
- **Notes** — Quick notes on your dashboard
- **Embed** — iFrame any webpage

[Learn more about Widgets →](./widgets.md)

### 🤖 AI Features

Let AI help you stay organized:

- **Auto-categorization** — AI suggests tags and folders
- **Smart summaries** — Get key points from any webpage
- **AI search** — Find bookmarks using natural language
- **Content translation** — Read any language

[Learn more about AI Features →](./ai.md)

### 📄 Multiple Pages

Separate contexts for better focus:

- Create pages for Work, Personal, Research, etc.
- Each page has its own layout and widgets
- Quick switch between pages
- Share pages with others (Pro)

[Learn more about Pages →](./pages.md)

### 🔌 Browser Extension

Save bookmarks without leaving the page:

- One-click save to NavHub
- Auto-fill title and description
- Choose folder and tags
- Screenshot capture
- Works on Chrome, Edge, Firefox

[Learn more about Browser Extension →](./extension.md)
