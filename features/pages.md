# Multiple Pages

Create separate pages for different parts of your life. Keep work, personal, and hobby content organized in their own spaces.

## Understanding Pages

Each page in NavHub is an independent dashboard with:

- Its own layout and widgets
- Its own bookmark collections
- Custom theme and colors
- Shareable link (Pro)

## Creating a Page

1. Click your current page name in the sidebar
2. Click **+ New Page**
3. Enter a page name
4. Choose a layout template (optional)
5. Click **Create**

## Page Templates

Start with a template or build from scratch:

| Template | Description |
|----------|-------------|
| Blank | Empty canvas |
| Productivity | Clock, to-do, bookmarks |
| News Reader | RSS feeds, weather |
| Developer | Search, docs, tools |
| Minimal | Just a search bar |

## Managing Pages

### Reordering Pages

- Drag and drop in the sidebar
- First page is your default home

### Renaming a Page

1. Right-click the page name
2. Select **Rename**
3. Enter new name
4. Press Enter

### Deleting a Page

1. Right-click the page name
2. Select **Delete**
3. Confirm deletion

**Note:** Bookmarks in the page are moved to Uncategorized, not deleted.

### Page Settings

Click the gear icon next to page name:

| Setting | Description |
|---------|-------------|
| Name | Page display name |
| Icon | Emoji or icon |
| Color | Theme color accent |
| Default | Set as home page |
| Privacy | Public / Private / Link sharing |

## Sharing Pages (Pro)

Share your curated pages with others:

### Public Pages

Anyone with the link can view:

1. Go to Page Settings
2. Set Privacy to **Public**
3. Copy the share link
4. Share with anyone

### Private Link Sharing

Only people with the exact link can view:

1. Go to Page Settings
2. Set Privacy to **Link Sharing**
3. Generate a unique link
4. Share with specific people

## Tips

1. **Don't overcrowd** — Better to have more pages than cluttered pages
2. **Use keyboard shortcuts** — `1-9` switches to pages 1-9
3. **Review periodically** — Archive unused pages
4. **Start with templates** — Customize from there
