# Upgrade Guide

Ready to unlock Pro features? Here's how to upgrade your NavHub account.

## Before You Upgrade

Make sure you understand what you're getting:

- [Free vs Pro Comparison](./free-vs-pro.md)
- [Pricing Options](./pricing.md)

## Upgrade Steps

### Step 1: Sign In

1. Go to [navhub.info](https://navhub.info)
2. Sign in to your account
3. Make sure you're on the account you want to upgrade

### Step 2: Go to Account Settings

1. Click your avatar in the top right
2. Select **Settings**
3. Click **Account** in the sidebar

### Step 3: Choose Your Plan

1. Click **Upgrade to Pro**
2. Select your billing cycle:
   - Monthly ($5.99/month)
   - Quarterly ($14.99/quarter) — 17% savings
   - Yearly ($49.99/year) — 30% savings
   - Lifetime ($149 one-time) — Best value

### Step 4: Enter Payment Details

1. Enter your payment method
2. Add billing address if required
3. Apply discount code if you have one
4. Review the total

### Step 5: Complete Purchase

1. Click **Complete Purchase**
2. Wait for confirmation
3. Pro features activate immediately

## After Upgrading

Try these Pro-only features:

2. **Page sharing** — Create public pages

## Applying Discount Codes

Have a discount code? Here's how to use it:

1. Start the upgrade process
2. Look for "Have a discount code?" link
3. Enter your code
4. Click **Apply**
5. See discount reflected in total
6. Complete purchase

### Common Discount Codes

| Code Type | Where to Find |
|-----------|---------------|
| Early Adopter | Welcome email |
| Student | Apply in Settings after verification |
| Non-Profit | Email support for code |
| Referral | From friend's invite link |

## Switching Billing Cycles

Already Pro but want to change cycles?

1. Go to Settings → Account
2. Click **Manage Subscription**
3. Select **Change Billing Cycle**
4. Choose new cycle
5. Prorated credit applied automatically

## Troubleshooting

### Payment Declined

If your payment is declined:

1. Verify card details are correct
2. Check for sufficient funds
3. Try a different payment method
4. Contact your bank if issues persist

### Discount Code Not Working

If a code doesn't work:

1. Check expiration date
2. Verify correct spelling
3. Ensure minimum requirements met
4. Some codes are one-time use only
5. Contact support if valid code fails

### Pro Features Not Appearing

If features don't activate:

1. Sign out and back in
2. Clear browser cache
3. Wait 5 minutes for sync
4. Check Settings → Account for status
5. Contact support if issues persist

### Already Charged But No Access

If you've been charged but don't have access:

1. Check the correct account
2. Look for confirmation email
3. Contact support@navhub.info immediately
4. Include transaction ID if available

## Cancel Anytime

Remember, you can cancel anytime:

1. Go to Settings → Account
2. Click **Cancel Subscription**
3. Keep Pro until period ends
4. No data is ever deleted
