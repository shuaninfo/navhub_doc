## Who Should Choose Free?

The Free plan is perfect if you:

- Have fewer than 500 bookmarks
- Only need 2-3 dashboard pages
- Want to try NavHub before committing
- Use AI features occasionally
- Don't need advanced widgets

## Who Should Choose Pro?

Pro is worth it if you:

- Have a large bookmark collection (500+)
- Create multiple dashboard pages
- Rely heavily on AI features
- Need embed widgets for dashboards
- Want to share pages publicly
- Need priority support

## Upgrade Anytime

Not sure? Start with Free and upgrade when you need more:
