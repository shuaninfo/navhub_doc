# What is NavHub

NavHub is a **smart personal navigation platform** that helps you centralize your online resources, build a personalized homepage, and escape the chaos of browser bookmarks.

## Our Mission

> **One place for all your online destinations**

Traditional browser bookmarks have serious limitations:
- Too many bookmarks, impossible to find what you need
- No sync across browsers or devices
- Just links — no notes, no smart organization

NavHub solves these problems, making your online life organized and efficient.

## Core Features

### 📚 Bookmark Management

- **Smart organization** — Tags + folders for flexible categorization
- **Full-text search** — Search not just titles, but page content
- **AI auto-tagging** — Automatically categorize and label your bookmarks
- **Bulk import** — One-click import from Chrome, Firefox, Raindrop.io, and more

### 🧩 Widget System

- **Custom dashboard** — Drag-and-drop layout for your personal homepage
- **Rich widgets** — Clock, weather, to-dos, RSS feeds, search bar
- **Multiple pages** — Separate pages for work, life, learning

### 🤖 AI Assistant

- **AI summaries** — Extract key content from any webpage
- **Smart search** — Natural language search across your bookmarks
- **Translation** — One-click translation for foreign content

### 🔌 Browser Extension

- **One-click save** — See something good? Click and save instantly
- **Quick access** — New tab page becomes your NavHub
- **Cross-browser** — Works on Chrome, Edge, Firefox

## Who is NavHub for?

| User Type | Use Case |
|-----------|----------|
| **Information collectors** | Browse lots of content daily, need efficient organization |
| **Knowledge workers** | Build a personal knowledge base, quick reference lookup |
| **Developers** | Manage docs, API references, tool websites |
| **Students & researchers** | Organize papers, course materials, study resources |
| **Creatives** | Collect inspiration, design references, trend articles |

## Why Choose NavHub?

| Feature | Browser Bookmarks | NavHub |
|---------|-------------------|--------|
| Search | Title only | Full-text + AI semantic search |
| Organization | Nested folders | Tags + categories + smart suggestions |
| Cross-device sync | Browser account dependent | Independent account, any device |
| Homepage customization | None | Drag-and-drop widgets |
| AI capabilities | None | Auto-categorize, summarize, search |
