# Quick Start Guide

Get up and running with NavHub in 5 minutes.

## Step 1: Create Your Account

1. Go to [navhub.info/signup](https://navhub.info/signup)
2. Enter your email and create a password
3. Or sign up with Google, GitHub, or Apple
4. Verify your email (check spam folder)
5. You're in!

## Step 2: Explore Your Dashboard

After signing up, you'll see your first page with default widgets:

- **Clock** — Shows current time
- **Search** — Quick web search
- **Bookmarks** — Your saved links (empty for now)

Take a moment to look around. This is your personal homepage.

## Step 3: Add Your First Bookmark

### Method A: From NavHub

1. Click the **+ Add** button (top right)
2. Paste a URL (try: `https://github.com`)
3. NavHub auto-fills title and description
4. Add tags if you want (optional)
5. Click **Save**

### Method B: With Browser Extension

1. Install the extension ([Chrome](https://chrome.google.com/webstore) / [Firefox](https://addons.mozilla.org))
2. Visit any webpage
3. Click the NavHub extension icon
4. Click **Save**

[Full extension setup guide →](./install-extension.md)

## Step 4: Create a Folder

Organize your bookmarks with folders:

1. In the sidebar, click **+ New Folder**
2. Name it (e.g., "Work", "Reading", "Tools")
3. Drag bookmarks into the folder
4. Create nested folders if needed

## Step 5: Add a Widget

Customize your dashboard:

1. Click **+ Add Widget**
2. Choose a widget type:
   - **Weather** — See local forecast
   - **To-Do** — Track tasks
   - **RSS Feed** — News updates
3. Configure settings
4. Drag to position it

## Step 6: Try AI Features (Optional)

If you have a Pro plan or AI tokens:

1. Add a bookmark
2. Click the **Summarize** button
3. See AI-generated summary
4. Try searching with natural language

## Quick Tips

1. **Press `/`** to quickly search your bookmarks
2. **Drag and drop** to reorder widgets and bookmarks
3. **Right-click** for quick actions menu
4. **Use tags** liberally — they're more flexible than folders
5. **Install the extension** — it's the fastest way to save
