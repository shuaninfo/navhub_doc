# Import Bookmarks

Bring your existing bookmarks to NavHub from any browser or bookmark service.

## From Chrome

### Export from Chrome

1. Open Chrome
2. Press `Ctrl+Shift+O` (Windows) or `Cmd+Shift+O` (Mac)
3. Click the **three dots** menu (top right)
4. Select **Export bookmarks**
5. Save the HTML file

### Import to NavHub

1. Go to NavHub → Settings → Import/Export
2. Click **Import Bookmarks**
3. Select **Chrome/HTML**
4. Upload your exported HTML file
5. Review and confirm

**What's preserved:**
- Titles and URLs
- Folder structure
- Created dates (when available)

## From Firefox

### Export from Firefox

1. Open Firefox
2. Press `Ctrl+Shift+O` (Windows) or `Cmd+Shift+O` (Mac)
3. Click **Import and Backup**
4. Select **Export Bookmarks to HTML**
5. Save the file

### Import to NavHub

Same as Chrome — upload the HTML file in NavHub's import settings.

## From Safari

### Export from Safari

1. Open Safari
2. Go to **File → Export → Bookmarks**
3. Save the HTML file

### Import to NavHub

Upload the HTML file in NavHub's import settings.

## From Edge

### Export from Edge

1. Open Edge
2. Go to **Favorites** (Ctrl+Shift+O)
3. Click the **three dots** menu
4. Select **Export favorites**
5. Save the HTML file

### Import to NavHub

Upload the HTML file in NavHub's import settings.

## From Raindrop.io {#raindrop}

### Export from Raindrop

1. Go to Raindrop.io Settings
2. Select **Backups**
3. Click **Create Backup**
4. Download the HTML or CSV file

### Import to NavHub

1. Go to NavHub → Settings → Import/Export
2. Click **Import Bookmarks**
3. Select **Raindrop.io**
4. Upload your export file
5. Review mapping options

**What's preserved:**
- Titles and URLs
- Tags (converted to NavHub tags)
- Collections (converted to folders)
- Notes

## From Other Sources

### Generic HTML

Most bookmark managers export HTML in Netscape format. NavHub reads this format automatically.

### CSV Import

For custom data:

1. Prepare a CSV with columns: `url`, `title`, `description`, `tags`, `folder`
2. Go to NavHub → Settings → Import/Export
3. Select **CSV Import**
4. Map columns to NavHub fields
5. Import

## Import Options

When importing, you can configure:

| Option | Description |
|--------|-------------|
| **Folder mapping** | Keep original structure or flatten |
| **Tag handling** | Convert folders to tags, or keep separate |
| **Duplicate handling** | Skip, update, or create duplicates |
| **Date preservation** | Keep original dates if available |

## After Import

### Review Your Bookmarks

1. Check folders are organized correctly
2. Verify important bookmarks imported
3. Look for any duplicates

### Clean Up

1. Delete obvious duplicates
2. Merge similar folders
3. Add missing tags
4. Fix broken links

### Organize with AI

Let NavHub help organize:

1. Go to Settings → AI Features
2. Enable **Auto-categorization**
3. Run on imported bookmarks
4. Review AI suggestions

## Troubleshooting

### Import Taking Too Long

Large imports (1000+ bookmarks) may take a few minutes. Don't close the tab.

### Missing Bookmarks

- Check file size limits (max 10MB)
- Ensure file isn't corrupted
- Try exporting again from source

### Folder Structure Wrong

- Some export formats don't preserve deep nesting
- Manually reorganize after import
- Use tags for additional organization

### Encoding Issues

If titles look garbled:
- Ensure export is UTF-8 encoded
- Re-export from source with UTF-8 option
- Contact support if issues persist
