# Widget System

Widgets let you customize your NavHub dashboard into a personalized homepage. Add the tools you use most and arrange them exactly how you want.

## Available Widgets

### Clock Widget

Display time and date with style:

- Multiple time formats (12h/24h)
- Show seconds
- Multiple timezones
- Date display options
- Various visual styles

### Weather Widget

Current conditions and forecast:

- Current temperature and conditions
- 5-day forecast
- Multiple locations
- Celsius or Fahrenheit
- Auto-detect location or manual entry

### Bookmarks Widget

Quick access to your favorite links:

- Display bookmarks from a folder
- Grid or list view
- Custom icon sizes
- Show or hide descriptions
- Click to open in new tab

### To-Do Widget

Simple task management:

- Add and check off tasks
- Due dates
- Priority levels
- Recurring tasks (Pro)
- Sync with external calendars (Pro)

### RSS Feed Widget

Stay updated with news:

- Add any RSS feed URL
- Multiple feeds in one widget
- Auto-refresh interval
- Show thumbnails
- Read count tracking

### Search Widget

Custom search bar:

- Default search engine
- Multiple search providers
- Quick switch between engines
- Search history
- Voice search (where supported)

### Notes Widget

Quick notes on your dashboard:

- Rich text formatting
- Markdown support
- Auto-save
- Multiple notes per widget
- Color coding

### Embed Widget (Pro)

Embed any webpage:

- iFrame any URL
- Custom dimensions
- Auto-refresh option
- Authentication pass-through

## Managing Widgets

### Adding a Widget

1. Click the **+ Add Widget** button on any page
2. Browse or search the widget catalog
3. Select the widget type
4. Configure initial settings
5. Click **Add to Page**

### Moving Widgets

- **Drag and drop** — Click and hold any widget to move it
- **Snap to grid** — Widgets automatically align
- **Resize** — Drag corners or edges (where supported)

### Widget Settings

Click the **gear icon** on any widget to access:

- **Title** — Custom widget title
- **Size** — Widget dimensions (small, medium, large, custom)
- **Refresh** — Auto-refresh interval
- **Visibility** — Show/hide conditions
- **Style** — Colors, borders, shadows

### Removing a Widget

1. Hover over the widget
2. Click the **three dots** menu
3. Select **Remove**
4. Confirm deletion

## Layout Options

### Grid System

NavHub uses a flexible grid system:

- 12-column layout on desktop
- Widgets snap to columns
- Responsive on mobile (stacked)
- Consistent spacing

### Widget Sizes

| Size | Columns | Best For |
|------|---------|----------|
| Small | 2-3 | Clock, weather |
| Medium | 4-6 | Bookmarks, notes |
| Large | 6-12 | RSS feeds, embeds |
| Full Width | 12 | Search bar, headers |

### Responsive Behavior

On smaller screens:
- Widgets stack vertically
- Maintain order priority
- Some widgets collapse to compact mode
- Touch-friendly controls

## Tips

1. **Start simple** — Add 3-4 widgets, then expand
2. **Use multiple pages** — Don't crowd one page
3. **Prioritize above the fold** — Most important widgets at top
4. **Match your workflow** — Work page with work tools
