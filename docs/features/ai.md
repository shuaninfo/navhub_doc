# AI Features

NavHub uses AI to make bookmark management smarter and more efficient. From auto-categorization to natural language search, AI helps you stay organized without the manual work.

## AI Capabilities

### Auto-Categorization

When you save a new bookmark, NavHub's AI can:

- **Suggest tags** — Based on page content and your existing tags
- **Recommend folders** — Match with similar bookmarks
- **Detect category** — News, shopping, reference, social, etc.

**How to enable:**
1. Go to Settings → AI Features
2. Enable "Auto-categorization"
3. Choose: Suggest only, or Auto-apply

### AI Summaries

Get the key points from any webpage:

- **Auto-summary** — Generated when you save a bookmark
- **On-demand** — Click "Summarize" on any saved bookmark
- **Custom length** — Brief (1-2 sentences) or detailed (paragraph)

**Use cases:**
- Research articles — Get main findings quickly
- News articles — Core story without scrolling
- Product pages — Key specs and features
- Documentation — What this page covers

### Smart Search

Find bookmarks using natural language:

Instead of keywords, ask questions:
- "React tutorials I saved"
- "That article about productivity from last week"
- "Recipes with chicken"

The AI understands context and finds relevant matches even without exact keyword matches.

### Content Translation

Read bookmarks in any language:

- **Auto-detect** source language
- **One-click translate** to your preferred language
- **Side-by-side view** — Original and translated
- **Bookmark translated version** — Save for later

## AI Token System

NavHub's AI features use a token-based system:

### What are Tokens?

Tokens measure AI usage. Roughly:
- 1 token ≈ 4 characters of text
- A typical summary uses 500-1000 tokens
- Search queries use 100-200 tokens

### Token Allocation

| Plan | Monthly Tokens | Rollover |
|------|---------------|----------|
| Free | 10,000 | No |
| Pro | 100,000 | Yes (up to 200K) |

### Token Usage by Feature

| Feature | Typical Usage |
|---------|---------------|
| Auto-categorization | 100-200 tokens |
| Summary (brief) | 300-500 tokens |
| Summary (detailed) | 800-1200 tokens |
| Smart search | 100-200 tokens |
| Translation (per page) | 500-2000 tokens |

### Checking Token Balance

1. Click your avatar → Account
2. View "AI Tokens" section
3. See usage history and remaining balance

## AI Settings

Customize AI behavior in Settings → AI Features:

| Setting | Options |
|---------|---------|
| Auto-categorization | Off / Suggest / Auto-apply |
| Summary generation | Off / On save / Manual only |
| Summary length | Brief / Standard / Detailed |
| Smart search | Off / On |
| Translation language | Select preferred language |

## Privacy & AI

Your data and AI:

- **On-device processing** — When possible, AI runs locally
- **Encrypted transmission** — All data encrypted in transit
- **No training** — Your data is never used to train AI models
- **Opt-out available** — Disable AI features entirely

## Tips for AI Features

1. **Review suggestions** — AI isn't perfect, review auto-tags occasionally
2. **Build good tag vocabulary** — Better existing tags = better suggestions
3. **Use smart search naturally** — Phrase as you would ask a person
4. **Save tokens on bulk imports** — Disable auto-summary during imports
