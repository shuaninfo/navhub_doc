# Getting Started

Welcome to NavHub! This guide will help you get up and running quickly.

## Contents

- [Installation](./installation.md) - How to install NavHub
- [Quick Start](./quick-start.md) - Your first steps with NavHub
- [Configuration](./configuration.md) - Configure your instance

## Requirements

Before installing NavHub, make sure you have:

- Docker and Docker Compose (recommended)
- Or: Go 1.21+, Node.js 18+, PostgreSQL 13+

## Quick Install

```bash
# Clone the repository
git clone https://github.com/anthropics/navhub.git
cd navhub

# Start with Docker
docker-compose up -d
```

Visit `http://localhost:8080` to access your NavHub instance.
